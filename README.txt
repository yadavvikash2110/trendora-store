TRENDORA — FREE STATIC STOREFRONT

Files: index.html, fashion.html, decorations.html, perfumes.html, style.css, app.js.

Publish free with GitHub + Cloudflare Pages:
1. Sign in to GitHub and create a PUBLIC repository named trendora-store.
2. Upload every file in this folder to the repository root.
3. Sign in to Cloudflare and open Workers & Pages > Create application > Pages > Connect to Git.
4. Choose trendora-store. No build command is needed; set the output directory to / (or leave the static root setting as prompted).
5. Deploy. Cloudflare assigns a free *.pages.dev address.

Important: This is a front-end demo only. Cart is stored in the visitor's browser. No real orders, inventory, shipping, or payments are processed. Connect a secure backend and a payment provider such as Razorpay before commercial launch. Never put payment secret keys in app.js.
